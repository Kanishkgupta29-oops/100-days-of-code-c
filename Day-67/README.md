# Day 67 — Problem 117

**Section**: Logic Enhancers

## 📝 Problem Statement
Write a program to take two sorted arrays of size m and n as input. Merge both the arrays such that the merged array is also sorted. Print the merged array.

## 🧪 Test Cases
### Test Case 1
- **Input**: `nums1 = [2,7,11,15] nums2 = [4,8,10]`
- **Expected Output**: `2 4 7 8 10 11 15`

### Test Case 2
- **Input**: `nums1 = [1,2,7] nums2 = [9,10,17]`
- **Expected Output**: `1 2 7 9 10 17`

### Test Case 3
- **Input**: `nums1 = [-10,-2,7] nums2 = [-3, -1, 7]`
- **Expected Output**: `-10 -3 -2 -1 7 7`
