## 📝 Problem Statement

## 🧪 Test Cases

- **Input**: `nums1 = [0,3,2,4]`
- **Expected Output**: `1`

### Test Case 2
- **Input**: `nums1 = [1,2,3]`
- **Expected Output**: `0`

### Test Case 3
- **Input**: `nums1 = [0,4,3,1,5]`
- **Expected Output**: `2`
