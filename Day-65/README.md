# Day 65 — Problem 115

**Section**: Logic Enhancers

## 📝 Problem Statement
Write a program to take two strings s and t as inputs (assume all characters are lowercase). The task is to determine if s and t are valid anagrams, meaning they contain the same characters with the same frequencies. Print "Anagram" if they are, otherwise "Not Anagram".

## 🧪 Test Cases
### Test Case 1
- **Input**: `s = "anagram", t = "nagaram"`
- **Expected Output**: `Anagram`
- **Explanation**: The strings contain the same characters with the same frequencies.

### Test Case 2
- **Input**: `s = "rat", t = "car"`
- **Expected Output**: `Not Anagram`
- **Explanation**: The strings do not contain the same characters.
